# Security policy

Please report suspected vulnerabilities privately to
**security@orgloom.com**. Do not open a public GitHub issue for a security
report.

Include a description of the issue, its expected impact, reproduction steps,
and proof-of-concept code when available. We aim to acknowledge reports within
three business days and provide an initial assessment within seven business
days.

The hosted Org Loom service at [orgloom.com](https://orgloom.com) is in scope.
Third-party self-hosted deployments and scanner output without a demonstrated
impact are out of scope. We do not currently operate a paid bug bounty.

Please keep vulnerability details confidential until a fix is available. We
will coordinate a disclosure timeline and credit reporters on request.
